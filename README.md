# 📝 开发日志：火鸟虚拟歌姬文化研究会歌曲分享站

**当前版本状态：** 单页应用 (SPA) 核心架构已完善，全栈交互已彻底跑通。

---

### 🛠️ 一、 基础技术栈与架构

* **前端：** HTML5 / CSS3 / Vanilla JS (原生纯前端)
* **后端：** Node.js + Express
* **数据库：** SQLite3 (本地文件 `database.db`)
* **架构模式：** 基于原生 JS 控制 DOM 显隐实现的轻量级单页应用 (SPA)。

### 📁 二、 已实现核心功能模块

#### 1. 全局布局与交互 (UI/UX)

* **侧边导航栏：** 实现了固定在左侧的悬浮导航栏，支持汉堡菜单（☰）展开/收起及平滑挤压动画。
* **单页路由：** 实现了“首页”、“歌曲推荐”模块的无刷新平滑切换。

#### 2. 首页欢迎页视图 (`#homeView`)

* **视觉背景：** 全屏自适应自定义背景图 (`welcome-bg.jpg`) 配合深色遮罩。
* **粒子特效：** 纯手写 Canvas 鼠标互动粒子网络，支持连线与避让物理反馈。
* **动态文案：** 标题下方集成 5 秒自动轮播的打字机文案，并预留文案投稿入口 (✏️)。
* **社区温度：** 动态拉取并展示实时统计数据（例：当前已收录共鸣数、独立上传者 Vocaloider 数量）。

#### 3. 歌曲推荐瀑布流 (`#recommendView`)

* **高级视觉：** 赛博风“呼吸渐变底色 + 微缩科技波点”背景，搭配半透明毛玻璃（Frosted Glass）卡片。
* **响应式瀑布流：** 基于 CSS Grid（`auto-fill` + 顶部对齐）实现多列错落排版，自适应不同屏幕。
* **局部检索：** 纯前端实时过滤，支持通过歌名、歌手、情绪标签或上传者瞬间筛选。
* **点赞系统 (全栈)：** 前端缩放变红特效 + 后端 API 持久化更新，含单页单次访问的防抖限制。
* **高光动效：** 用户发布新歌后自动切回瀑布流，新卡片触发 2.5 秒粉红色发光闪烁呼吸灯特效。

#### 4. 打歌弹窗与数据流 (`#addModal`)

* **API 抓取：** 实时调用 Apple Music (iTunes Search API) 搜索歌曲。
* **画质优化：** 正则拦截替换，自动获取 `600x600bb` 超高清专辑原图。
* **交互流：** 分步表单（输入搜索 -> 点击选中 -> 选择 Emoji 情绪标签 -> 填写昵称与留言 -> 提交发布）。

### 🗄️ 三、 数据库与 API 接口状态

**数据库结构 (`database.db`)：**

* **`songs` 表：** `id` (主键), `title` (歌名), `artist` (歌手), `cover` (封面URL), `tag` (标签), `message` (留言), `likes` (点赞数, 默认0), `recommender` (推荐人)。
* **`users` 表：** `id`, `username`, `password` (已建表，作为未来用户系统预留)。

**已跑通 API 路由 (`server.js`)：**

* `GET /api/songs`：拉取全量歌曲数据（按 ID 倒序排列）。
* `POST /api/songs`：提交新歌曲数据，返回生成的主键 `songId`。
* `POST /api/songs/:id/like`：指定歌曲点赞数 +1。

### 🚀 四、 待开发与未来计划

3. **用户账号系统：** 激活预留的 `users` 表，实现 Vocaloider 专属账号注册、登录及个人中心功能。
